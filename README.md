# Faberlic VK Bot

VK-бот для Гульчачак на vkbottle 4.x — адаптация TG-бота.

## Быстрый старт

```bash
cd c:\Users\Admin\Desktop\РАБОТА\projects\faberlic_vk
pip install -r requirements.txt
copy .env.example .env
# Открой .env и заполни VK_TOKEN и ADMIN_IDS
python bot_vk.py
```

## Настройка

1. **VK_TOKEN** — ключ доступа сообщества ВКонтакте (Управление -> Работа с API -> Создать ключ, разрешения: сообщения + фото)
2. **ADMIN_IDS** — твой VK ID (число из адресной строки профиля), через запятую если несколько
3. Папка `media/` — сюда кладёшь фото (gulchachak.jpg, gift_promo.jpg и т.д.)
4. Ссылки и тексты меняются через команду `настройки` в чате бота
